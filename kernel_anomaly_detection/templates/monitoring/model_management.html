AI Behavioral Analysis Pipeline (Kernel Space -> User Space -> ML Scoring)

The system utilizes an unsupervised Isolation Forest algorithm to isolate anomalies instead of profiling normal points. Since malicious kernel events (such as unauthorized privilege escalation or burst file encryption) have abnormal system call patterns and resource signatures, they require fewer random partition splits to isolate, resulting in high anomaly scores ($0.0 \to 1.0$).

1. Kernel eBPF Telemetry

Hooks into tracepoints sys_enter_execve, openat, connect, setuid via BPF perf buffer.

2. Behavioral Feature Vector

Normalizes 10 kernel dimensions using StandardScaler before feeding into tree isolation.

3. Calibrated Threat Scoring

Calibrates raw decision function to continuous risk score and categorizes into Normal, Low, Medium, High, Critical.
